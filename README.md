# SCP // Secure Access Terminal

Стильный веб-сайт в эстетике защищённого компьютера-терминала **Фонда SCP**
с базой данных аномальных объектов. Адаптивен под ПК, планшет и мобильные
устройства.

![status](https://img.shields.io/badge/SITE--19-ONLINE-00e08a?style=flat-square)
![clearance](https://img.shields.io/badge/CLEARANCE-L1--O5-ffb627?style=flat-square)

## Возможности

- **Загрузочная последовательность** (BIOS/POST) и экран авторизации с выбором уровня допуска (L1–O5)
- **Реестр аномалий** — карточки объектов с классами опасности (Safe / Euclid / Keter / Thaumiel)
- **Поиск и фильтрация** по классу и ключевым словам
- **Досье объекта** в стиле секретного документа с эффектом цензуры `█████`
- **Контроль доступа** — объекты выше вашего уровня допуска заблокированы
- **Сканер аномальной активности** с анимированным радаром
- **Интерактивный терминал** с командами (`help`, `list`, `info`, `random`, `classes` …)
- CRT-эффекты (сканлайны, виньетка, мерцание), уважает `prefers-reduced-motion`
- **PWA**: устанавливается на телефон («добавить на главный экран»), запускается
  в полноэкранном режиме, работает офлайн (service worker), корректно учитывает
  «чёлку»/закругления экрана (safe-area)

## Технологии

Чистый **HTML + CSS + JavaScript**, без зависимостей и шагов сборки.

| Файл | Назначение |
|------|-----------|
| `index.html` | Разметка интерфейса |
| `styles.css` | Стили, тема, анимации, адаптив |
| `app.js` | Логика: загрузка, навигация, БД, модалки, терминал |
| `data.js` | База данных объектов SCP |

## Локальный запуск

Достаточно открыть `index.html` в браузере. Либо поднять локальный сервер:

```bash
python3 -m http.server 8080
# затем откройте http://localhost:8080
```

## Деплой на GitHub Pages

Репозиторий настроен на автодеплой через GitHub Actions
(`.github/workflows/deploy.yml`). Чтобы включить:

1. Откройте **Settings → Pages** в репозитории на GitHub.
2. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
3. Запушьте изменения — workflow соберёт и опубликует сайт.

После деплоя сайт будет доступен по адресу
`https://<ваш-логин>.github.io/scp-box/`.

## Терминал — команды

| Команда | Действие |
|---------|----------|
| `help` | Список команд |
| `list` | Все объекты реестра |
| `info SCP-173` | Открыть досье объекта |
| `random` | Случайный объект |
| `classes` | Статистика по классам |
| `whoami` | Текущая сессия |
| `clear` | Очистить экран |
